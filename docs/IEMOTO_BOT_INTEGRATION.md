# 家元相談所 / 家元bot 連携メモ

## 目的

家元botは、LINE上で人生経験豊富な親方・師匠として相談を受けるAIです。
商品販売を最終目的にせず、信頼を積み重ねた結果として必要な時だけ商品やデザイン提案へつなげます。

## LINE Harnessが持つべき情報

家元botの親密度・常連感は、LINE Harness側の友だち情報を正とします。

- メッセージ回数
- 初回 / リピーター判定
- 最終会話日時
- 友だちタグ
- シナリオ到達状況
- 家元相談モード利用回数
- 画像・デザインモード利用回数
- 過去の相談カテゴリ
- 必要に応じた直近会話要約

## 家元bot側の使い方

家元botは、LINE Harnessから取得した回数・タグ・履歴に、家元相談所側の直近会話要約を足して返答距離を調整します。

例:

- 初回: `今日はどうした？`
- 2〜3回目: `また来たな。今日は何を抱えてきた。`
- 4〜7回目: `お前の迷い方は、少し分かってきた。`
- 8回目以降: `よく来た。こういう時、お前は一人で抱え込みすぎる。`

## モード分離

- 家元相談所LINE: 家元相談と公式LINEデザインボットを振り分ける。
- 口コミレビュー職人: 別LINE運用。家元相談所のLINE入口からは転送しない。

## 注意

- LINE Harnessは回数・タグ・状態の正本。
- 家元botは人格・相談文・商品提案ゲート・安全ゲートを担当。
- 秘密情報、APIキー、LINEトークンはdocsに保存しない。
